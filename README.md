# Ательє Шефа PRO — стартовий прототип

Україномовний адаптивний вебдодаток у темному преміальному стилі (чорний/золотий).

## Запуск
Відкрийте `index.html` у браузері для швидкого перегляду. Для встановлення як PWA потрібен HTTPS-хостинг (наприклад, GitHub Pages або Render Static Site), після чого відкрийте сайт у Chrome на Android → меню ⋮ → «Встановити додаток» / «Додати на головний екран».

## Важливо
Це стартовий локальний прототип: записи зберігаються в localStorage браузера на одному пристрої. Немає реєстрації, хмарної синхронізації, реальної AI-інтеграції, платежів чи серверного блокування користувачів. Завантажений `security_spec` описує вимоги до Firebase/Firestore Rules, але сам по собі не є готовою конфігурацією безпеки або бекендом. Перед публічним запуском потрібно реалізувати Firebase Auth, Firestore, Security Rules, Cloud Functions/серверну перевірку платежів і перевірити їх тестами.
